03 — Results

AVIF is encoded with a bundled WASM encoder (not your browser's native support, which is unreliable), so it works the same everywhere — it's just slower per image than WEBP/JPG. HT Image Compressor aims a little under your target (about 1.5 KB) rather than right at it, so results consistently land safely below the number you set instead of risking going over. If an image is already smaller than the target and doesn't need a format or dimension change, it's left completely untouched — no re-encoding, no risk of accidentally growing it. If it does need converting, the result is capped at the original file size so conversion never makes a small file bigger. PNG is lossless, so it has no quality dial — HT Image Compressor approaches a PNG target only by adjusting resolution, so results are less exact than WEBP/JPG. For WEBP/JPG, if compression alone can't reach a small target at full resolution, you'll see a note with a one-click option to force it by reducing resolution too. All processing happens locally in your browser; files are never sent anywhere.
